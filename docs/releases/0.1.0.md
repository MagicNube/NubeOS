## Actualizar la instalación

1. Cerrar NubeOS antes de reemplazar el ejecutable. Evitar usar simultáneamente la versión de desarrollo y la instalada.
2. Desde la raíz del proyecto, ejecutar `npm run tauri build -- --bundles nsis`.
3. Ejecutar el instalador generado en `src-tauri/target/release/bundle/nsis/`. Mantener la misma carpeta de instalación y el mismo identificador.
4. No eliminar la carpeta de datos ni marcar una opción de borrado de datos al desinstalar. Hacer una copia preventiva antes de actualizaciones que modifiquen el esquema SQLite.

El acceso de inicio seguirá apuntando al mismo ejecutable. Las siguientes versiones se actualizarán manualmente; no se ha añadido un actualizador automático.
