# Módulos

Cada módulo tiene tres documentos antes de su implementación:

1. `spec.md`: comportamiento, requisitos, restricciones y criterios de aceptación.
2. `design.md`: entidades, límites, flujos y contratos sin implementar código.
3. `tasks.md`: trabajo pequeño, ordenado y verificable.

Si una decisión afecta a la arquitectura general, se propone una ADR antes de crear tareas de implementación.
