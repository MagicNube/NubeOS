# Visión de NubeOS

- Estado: Aprobada por Nube
- Última actualización: 2026-08-02

## Problema

La información personal útil para tomar decisiones diarias suele vivir dispersa entre varias aplicaciones, notas y memoria: gastos, hábitos, rutinas, compras, lecturas y proyectos. Esto añade fricción, obliga a reconciliar datos manualmente y entrega información privada a servicios que no controlamos.

NubeOS es una aplicación personal para una única persona: su propietario. Debe servir como un espacio de confianza donde organizar su vida sin tratar sus datos como un producto.

## Propuesta de valor

NubeOS reúne flujos personales recurrentes en una aplicación de escritorio privada, modular y local-first. Cada módulo resuelve un problema concreto con datos que pertenecen al usuario, siguen siendo utilizables sin conexión y pueden exportarse.

No busca sustituir todas las herramientas existentes ni convertirse en una plataforma generalista. Busca reducir fricción en las partes de la vida personal que el usuario consulta y actualiza con frecuencia.

## Principios de producto

- **Privada por defecto.** No hay publicidad, analítica de terceros ni venta de datos.
- **Local-first.** El uso diario no depende de un servicio remoto.
- **Modular y enfocada.** Cada área tiene un propósito claro; no se añaden funciones por acumulación.
- **Clara y calmada.** La interfaz prioriza legibilidad, foco y el mínimo ruido visual.
- **Datos portables.** El usuario conserva control y puede exportar sus datos en formatos razonables.
- **Evolución deliberada.** Las necesidades reales del uso personal guían el orden de los módulos.

## Alcance inicial

La primera etapa del proyecto establece las fundaciones de una aplicación de escritorio local y desarrolla los módulos de forma vertical, uno cada vez.

El primer módulo a especificar es el **planificador de comidas y compras**. Los siguientes módulos candidatos, sin un orden aún comprometido, son:

- Hábitos y rutinas.
- Finanzas personales.
- Documentos.
- Proyectos.
- Lectura.
- Series.

## Fuera de alcance inicial

- Funciones sociales, colaboración multiusuario o perfiles compartidos.
- Dependencia obligatoria de una nube o de una cuenta externa.
- Aplicación móvil y sincronización entre dispositivos.
- Importación automática de datos bancarios o integración con servicios de terceros.
- Recomendaciones basadas en IA o automatizaciones opacas.
- Intentar reproducir productos completos como Notion, YNAB o Todoist.

Estas ideas podrán evaluarse más adelante como propuestas independientes, pero no condicionan la primera versión.

## Métricas de éxito personales

La visión se considera encaminada si, tras usar NubeOS de forma continuada:

- El usuario elige NubeOS como lugar principal para los flujos que ya cubra.
- La planificación semanal de comidas y la lista de compra requieren menos trabajo manual que antes.
- Los datos personales relevantes están localizados, son comprensibles y se pueden recuperar.
- Añadir o consultar información cotidiana se siente suficientemente rápido como para no volver a una nota temporal.
